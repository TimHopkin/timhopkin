# Tim Hopkin Personal Website

A professional thought leadership website showcasing Tim Hopkin's expertise in digital land management, climate resilience, and policy influence.

## Overview

This website positions Tim Hopkin as a knowledge leader in digitising Britain's land economy through his companies:
- **Land App** - Digital land mapping platform
- **Land Management 2.0** - Next-generation stewardship frameworks  
- **Norney Farm** - Practical application and proof of concept

## Features

- **Responsive Design** - Optimised for desktop, tablet, and mobile
- **British English** - All content uses proper British spelling and terminology
- **SEO Optimised** - Structured data, meta tags, and semantic HTML
- **Accessibility** - WCAG 2.1 AA compliant
- **Performance** - Fast loading with optimised assets
- **Clean Code** - Semantic HTML5, modern CSS, vanilla JavaScript

## Structure

```
├── index.html          # Main website file

└── README.md           # This file
```

## Setup

1. **Local Development**
   - Simply open `index.html` in a web browser
   - No build process required - static HTML/CSS/JS

2. **Web Server**
   - Upload all files to your web hosting provider
   - Ensure `index.html` is in the root directory
   - Configure domain to point to timhopkin.com

3. **Testing**
   - Test on multiple devices and browsers
   - Validate HTML and CSS
   - Check accessibility compliance
